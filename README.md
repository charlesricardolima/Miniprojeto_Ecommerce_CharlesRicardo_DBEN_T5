## Objetivo

Desenvolver um sistema simples de gerenciamento de e-commerce utilizando TypeScript e Node.js, aplicando conceitos de programação, tipagem, funções, arrays, módulos e regras de negócio.

## Funcionalidades previstas

- Cadastro e gerenciamento de produtos.
- Cadastro e consulta de clientes.
- Gerenciamento do carrinho de compras.
- Finalização de pedidos.
- Controle de estoque.
- Relatórios de vendas.

## Tecnologias utilizadas

- TypeScript
- Node.js
- Git e GitHub

## Estrutura do projeto

O código está organizado na pasta `src`, com arquivos separados para produtos, clientes, carrinho, pedidos, relatórios e tipos.

O arquivo `main.ts` é responsável por demonstrar as funcionalidades da aplicação.

## Como executar

Instalar as dependências:

```bash
npm install
```

Compilar o projeto:

```bash
npm run build
```

Executar a aplicação:

```bash
npm start
```

## Regras de negócio

As regras de cadastro, estoque, carrinho e pedidos serão documentadas conforme a implementação das funcionalidades.

## Limitações

- Não possui interface gráfica.
- Não utiliza banco de dados.
- Os dados são armazenados em memória durante a execução.
